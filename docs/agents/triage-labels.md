# Triage Labels

The five canonical triage states used by the `triage` skill (as `status:` values in issue frontmatter):

| Role | String |
|------|--------|
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| AFK-agent-ready | `ready-for-agent` |
| Human implementation needed | `ready-for-human` |
| Won't action | `wontfix` |
